    Training datasets¶

    Dataset Content License
    xlam-function-calling-60k (APIGen) 60k verified query/tools/answer triples, 3,673 APIs CC-BY-4.0, gated
    APIGen-MT-5k 5k multi-turn agent trajectories CC-BY-NC-4.0
    glaive-function-calling-v2 ~113k synthetic single- and multi-turn chats Apache-2.0
    hermes-function-calling-v1 Hermes <tool_call> format + JSON mode Apache-2.0
    hermes_reasoning_tool_use Tool use with reasoning traces Apache-2.0
    ToolACE ~11k dialogues over 26k synthesized APIs Apache-2.0
    Toucan-1.5M 1.5M trajectories from real MCP servers Apache-2.0
    When2Call Call / ask / refuse decisions CC-BY-4.0
    xlam-irrelevance-7.5k No-call (irrelevance) examples CC-BY-4.0
    argilla/apigen-function-calling xLAM 60k + Synth-APIGen merged for SFT CC-BY-4.0
    Nemotron-Agentic-v1 · Nemotron-Post-Training-v1 NVIDIA agentic and tool-calling SFT data CC-BY-4.0
    Agent-FLAN Agent tuning data incl. negative samples Apache-2.0
    APIBench Original Gorilla API-call data Apache-2.0
    ToolBench 16k+ RapidAPI APIs, ~126k solution paths (download via repo) see repo

    Always check the license before commercial use.
